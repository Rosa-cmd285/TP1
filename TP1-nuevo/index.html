🚀 Flujo de Trabajo con Git y GitHub (Fork & Clone)

  1. 1. Hacer Fork del Repositorio de Cátedra:

    Ingresa a github.com/UNJU-Teoria-de-Sistemas-Operativos/TP1 y haz clic en el botón "Fork" (arriba a la derecha) para crear una copia en tu cuenta personal.

  2. 2. Clonar tu Fork Personal:

    Abre la terminal en tu computadora y clona tu repositorio bifurcado (reemplazando TU_USUARIO):

    git clone https://github.com/TU_USUARIO/TP1.git
  3. 3. Resolver los 10 Ejercicios:

    Abre index.html en tu navegador, completa tus datos individuales y resuelve las consignas interactivas.

  4. 4. Exportar y Guardar el Archivo JSON:

    Al llegar al 100%, pulsa "Exportar Respuestas (.json)" y guarda/reemplaza el archivo respuestas_tp1.json dentro de la carpeta clonada del repositorio.

  5. 5. Autoevaluación Local (Opcional pero muy recomendado):

    Verifica tu calificación formativa antes de entregar ejecutando:

    python autograder_tp1.py respuestas_tp1.json
  6. 6. Guardar Cambios y Subir a tu Fork:
    git add respuestas_tp1.json
    git commit -m "Entrega TP1 - [Tu Nombre y Apellido]"
    git push origin main
  7. 7. Entrega Final:

    Copia el enlace de tu repositorio Fork (https://github.com/TU_USUARIO/TP1) y entrégalo según las indicaciones de la cátedra.
